## Traky: Plataforma de análisis de precios de tiendas en línea

Traky es una aplicación basada en Python que recopila información de tiendas en línea con el objetivo de analizar y mostrar los productos más baratos disponibles. Esta herramienta utiliza tecnologías como FastAPI, Pandas y Redis para obtener, procesar y almacenar los datos de precios de productos de diversas tiendas en línea.

### Características clave

- Recopilación de datos: Traky se encarga de extraer información sobre precios y productos de diferentes tiendas en línea.
- Análisis de precios: Utilizando algoritmos y técnicas de análisis, Traky determina los productos más baratos en función de los datos recopilados.
- Interfaz de usuario intuitiva: La aplicación proporciona una interfaz de usuario fácil de usar para buscar productos y comparar precios.
- Almacenamiento en caché con Redis: Traky utiliza Redis para almacenar en caché los datos recopilados, lo que agiliza el proceso de análisis y consulta de productos.

### Tecnologías utilizadas

- Python: Lenguaje de programación principal utilizado para el desarrollo de Traky.
- FastAPI: Un framework rápido (high-performance) para construir APIs web con Python.
- Pandas: Una biblioteca de análisis de datos en Python que proporciona herramientas eficientes para manipular y analizar datos estructurados.
- Redis: Una base de datos en memoria de código abierto que se utiliza como sistema de almacenamiento en caché en Traky.
